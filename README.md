# BloodboundSMP Releases

This public repository is used only for BloodboundSMP release downloads.

- Latest releases: https://github.com/mhinnen2310/BloodboundSMP/releases
- Source code is maintained privately in `mhinnen2310/BloodboundSMP-source`.

## Server Owners
Download the full release set from the Releases page. Each release contains:

- all BloodboundSMP plugin jars
- `mitchsmp-release-manifest.json` for the in-game updater
- SHA256 checksums
- resourcepack zip
- release notes

Do not install random individual files from the Code tab. Use the packaged release assets only.
