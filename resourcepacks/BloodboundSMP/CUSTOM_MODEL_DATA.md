# BloodboundSMP Custom Item Models

Modern item-model components:

- Boss Shard: `bloodbound:boss_shard`
- Corrupted Heart: `bloodbound:corrupted_heart`
- Bloodbound Archfiend boss visual: `bloodbound:archfiend`

CustomModelData fallbacks:

- Boss Shard: `NETHER_STAR`, `910001`
- Corrupted Heart: `ECHO_SHARD`, `910002`
- Bloodbound Archfiend boss visual: `NETHER_STAR`, `910100`

Normal Nether Stars and Echo Shards use the vanilla fallback model unless the plugin writes a Bloodbound item-model component.
